Estudio digital desde Jaén: diseño y desarrollo web, experiencias interactivas y conexión entre herramientas. También desarrollo herramientas de apoyo a la preparación de contenido con modelos de IA y revisión humana.

### Mesa Clara · App publicada para dividir cuentas

App de iPhone para repartir una cuenta por conceptos y personas. Trabaja con céntimos enteros, reparte los extras proporcionalmente al consumo y permite compartir el resultado. Publicada en la App Store desde octubre de 2026.

Swift · SwiftUI · Lógica de cálculo y pruebas

[App Store](https://apps.apple.com/es/app/mesa-clara-divide-cuentas/id6818203298) · [Caso de proyecto](proyectos/mesa-clara.md)

### Aligera · App publicada para gestionar la fototeca

App de iPhone para revisar archivos grandes, preparar versiones comprimidas y detectar fotos duplicadas o parecidas. La persona revisa qué conservar. Disponible en la App Store.

SwiftUI · AVFoundation · Vision

[App Store](https://apps.apple.com/es/app/aligera/id6807391194) · [Caso de proyecto](proyectos/aligera.md)

### Matiza · Prototipo de editor fotográfico

Editor para iOS con ajustes no destructivos, máscaras locales y un motor de pincel con Metal. Un proyecto para explorar procesamiento de imágenes e interacción de edición.

SwiftUI · Metal · Core Image

[Caso de proyecto](proyectos/matiza.md)
