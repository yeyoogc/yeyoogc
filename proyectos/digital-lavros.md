# Digital Lavros · Diseño, desarrollo web y automatización

Digital Lavros es mi estudio digital, desde Jaén. El proyecto reúne diseño y desarrollo web, contenido visual y conexión entre herramientas para empresas. La web permite explicar el alcance de los servicios, explorar conceptos interactivos y enviar una solicitud de proyecto.

## Desarrollo web

La web está construida con Next.js y TypeScript. Separa las páginas, los componentes de interfaz, el contenido de servicios y las integraciones. Los formularios validan las entradas, incorporan medidas contra envíos repetidos y preparan mensajes de contacto mediante un proveedor de correo. Los datos de contacto y la URL canónica se centralizan para evitar contradicciones entre páginas.

El portfolio contiene conceptos de demostración, incluidos recorridos visuales y formularios simulados. Están identificados como demos: no se presentan como clientes, campañas reales de las marcas o resultados comerciales. La web pública permite explorar estas experiencias.

## Automatización e IA aplicada

He trabajado en una fábrica de apoyo al contenido con Python: instrucciones editoriales, preparación de texto y recursos visuales, integración con servicios de modelos y entrega de materiales para revisión. El código contempla distintos motores y separa la generación de la decisión editorial. Las rutas experimentales y la operación continua de esos flujos requieren verificaciones propias; la existencia del código no acredita por sí sola su funcionamiento permanente.
